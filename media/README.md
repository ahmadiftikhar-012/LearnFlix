# Local media files

The project includes `sample-intro.wav`, a short original narration used by the HTML audio player.

For local video lessons, place only videos you created or have permission to use in this folder. Add the project-relative MP4 path to an entry in `../js/content-library.js`, for example `media/html-basics.mp4`. Keep filenames short and avoid personal computer paths. Include the MP4 when sharing the project if you want it to play on another device. The current catalogue uses YouTube for its actual course videos, so an MP4 is optional.
