    How the course library is maintained

    For this client-side project, course entries live in one JavaScript file. Add a course there with a unique ID, title, category, level, description, and source. Use a YouTube playlist ID for an online playlist, or a project-relative MP4 path for a local video. The page creates the category filter and course cards from that list.

    There is no server or admin upload screen in this version. Updating the library means editing the file and sharing the updated project folder. YouTube videos require an internet connection and may be unavailable if their owner blocks embedding or removes them. Preview the site through a local web server such as VS Code Live Server; embedded playback can fail when a page is opened directly as a local file.
