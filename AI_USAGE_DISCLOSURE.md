# AI use disclosure

I used OpenAI Codex to brainstorm project ideas, explore the page layout and
color theme, draft course descriptions, and explain HTML, CSS, and JavaScript
concepts when I got stuck on logic or syntax. AI also helped with the course
search and category filter, the Assignment 2 page layouts, and the Contact and
Register page interactions.

The complete `js/content-library.js` file was generated with AI. We added it as
an extra project feature to organize course and video information by subject and
provide course cards, search, category filters, and video selection. The
assignment brief did not specifically require this file. AI also helped
implement the local Register form preview so the demonstration validates in the
browser without sending personal information. I plan to study these
interactions so I can explain how they work.

I plan to keep reviewing and practising the AI-assisted code so I can explain
the design and behavior of LearnFlix.
